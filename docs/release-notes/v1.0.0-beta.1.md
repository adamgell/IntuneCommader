# IntuneCommander v1.0.0-beta.1

**The first public beta** of IntuneCommander — a Windows-native control plane for Microsoft Intune &
Entra device management, with a built-in audit/drift **time-machine**, a full diagnostics suite, and a
human-gated automation layer.

This is the ground-up successor to the original
[IntuneCommander](https://github.com/adamgell/IntuneCommander) (the .NET + React app / `ic.exe` CLI),
rebuilt as a native **Rust + WinUI 3** client over a hard-forked .NET Graph engine.

> 🧪 **This is a beta.** It's capable and in daily use, but expect rough edges. Please
> **[file issues](https://github.com/gellorg/intunecommander-release/issues)** — beta feedback is the
> whole point.

## Install

| Download | For |
|---|---|
| `IntuneCommander-1.0.0-beta.1-arm64.msi` | **Windows on ARM64** — recommended |
| `IntuneCommander-1.0.0-beta.1-x64.msi` | Windows on x64 |
| `IntuneCommander-1.0.0-beta.1-<arch>.msix` | MSIX / App-Installer or managed (Intune) deployment |
| `IntuneCommander-1.0.0-beta.1-win-<arch>.zip` | Portable — no install; run `Start-IntuneCommander.cmd` |

Run the MSI (double-click), then launch **IntuneCommander** from the Start Menu. Requires **Windows 11**
and the **[Windows App SDK runtime](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)**;
the .NET runtime is bundled. All installers are **code-signed with Azure Trusted Signing**. See the
bundled `docs/RUNBOOK.md` for prerequisites and a smoke test.

## What's inside

- **Manage 40+ Intune/Entra resource types** — device configs, compliance, Settings Catalog, Endpoint
  Security, apps & assignments, enrollment, Conditional Access, groups, tenant admin — with a
  consistent **view → edit → clone → delete → assign** flow. Every write shows a **diff preview + a
  confirmation** first, and is snapshotted so you can roll it back.
- **A time-machine for your tenant** — audit timeline, field-level **drift**, full-text **search**, and
  **point-in-time restore**.
- **Diagnostics** — CMTrace/IME log explorers, dsregcmd, deployment, DNS, error-code lookup, registry,
  Event Log, Sysmon, Secure Boot, timeline correlation, and a one-click diagnostics collector. All
  local, no sign-in required.
- **Platform features** — GitOps-style plan/apply, a **blast-radius simulator**, a queryable **tenant
  digital twin**, continuous **posture scoring** (CIS/OIB/E8/NIST) with audit evidence, multi-tenant
  **fleet** management, and a **policy-pack / playbook ecosystem**.
- **Human-gated automation** — an optional watcher proposes remediations; **you approve the exact diff
  before anything is written.** Nothing is ever applied automatically.

## Coming from the original IntuneCommander?

- Your saved **tenant profiles carry over** on the same Windows machine.
- Your **config backups import directly** (the `IntuneManagement`-compatible JSON format) via
  **Backup & Restore → Import**.
- The old file-based `export → diff → alert` CLI workflow is replaced by the always-on time-machine.

## ⚠️ Beta notes — read before using on a real tenant

- **Writes hit your live tenant. There is no sandbox mode.** The diff-preview → confirm gate protects
  you, but a confirmed change is real. Try edits first on low-risk surfaces (Scope Tags, Device
  Categories).
- Some platform features are **preview-quality** in this build (cross-MDM is experimental; a few
  analytics were validated against recorded data). They're labelled in-app.
- **Conditional Access is read-only by design** — IntuneCommander will never write it.
