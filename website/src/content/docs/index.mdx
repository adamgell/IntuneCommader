IntuneCommander is a Windows-native desktop tool that unifies **local diagnostics** (cmtrace heritage)
with **Entra & Intune management** (IntuneCommander heritage) — and pulls cloud context _down onto
the endpoint_, so every log line carries its tenant reality. You stop alt-tabbing between a log
viewer and the portal; the answer is on the line.

<CardGrid>
	<Card title="Diagnostics">
		Live-tail Intune logs, `dsregcmd`, Sysmon, the Windows Event Log, Secure Boot, and a
		Windows/Intune error-code database — correlated on one timeline.
	</Card>
	<Card title="Management">
		List, view, and safely edit Intune & Entra surfaces. Every write is diff-previewed,
		confirmed, and snapshotted first.
	</Card>
	<Card title="Time-machine">
		An append-only audit, drift detection, full-text search, and **point-in-time restore** —
		roll any change back to a past snapshot.
	</Card>
</CardGrid>
